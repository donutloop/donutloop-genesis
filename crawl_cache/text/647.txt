What is ModCon? A Shared Foundation for Scientific AI ModCon provides the capabilities, tools, and services that research teams need to move faster, build better models, and produce results that are reliable, reproducible, and ready to scale. All capabilities are delivered through the American Science Cloud (AmSC), a secure, federated, science-optimized platform that connects DOE’s computing systems, experimental facilities, data resources, and high-performance networks. Core Capabilities and Services Baseline AI R&D Capabilities (BASE) Reusable methods, frameworks, and tools that underpin accelerated AI. Best Practices for Scientific Workflows (BPSW) Guidance, patterns, and tools for integrating AI into scientific workflows. Data Brokers & Standards (DBS) Centralized access to FAIR datasets with standards and governance tools. IP & Partnership Formation (IPPF) Streamlined frameworks for collaboration across labs, industry, and academia. Resources Tools for Building AI Models Discover foundational resources developed through ModCon, including models, data, and agent frameworks. These assets support research, development, and collaboration across the scientific AI community, with code and documentation available on GitHub . Agent Cards The Genesis Mission agent card template is a structured description of an AI agent that makes the agent discoverable, reusable, and interoperable. It documents what the agent does, who provides it, how to invoke it, what skills and tools it exposes, what inputs and outputs it supports, its authentication requirements, runtime details, intended uses, limitations, and safety considerations. In Genesis, agent cards help users and other agents understand whether an agent is appropriate for a task and how it can be safely integrated into workflows. Agent Card Template Genesis Skills is a collection of Claude Code skills that give Claude specialized capabilities for scientific discovery and engineering workflows. Part of the Genesis Mission , these skills encode domain expertise, connect to scientific data sources, and provide reproducible patterns for computational research/ Skills follow the Agent Skills open standard, making them portable across AI tools while leveraging Claude Code's extended features. Genesis Mission Agent Skills Agentic Capabilities Data Cards The Genesis Mission data card template is a structured metadata document that describes a dataset — what it is, where it came from, who created it, how it can be accessed, and how it can be used. Datacards serve both humans (who need to understand a dataset before using it) and machines (automated pipelines that ingest, catalog, and validate datasets). In Genesis, every dataset — regardless of size, sensitivity, or publication state — should have a data card. A data card can be created at the same time as the dataset, or as early in the workflow as possible Data Card Template Data Card Examples Map of Repositories Model Cards The Genesis Mission model card template is a structured description of an AI model that explains what the model is, who developed it, what data and methods were used to train or fine-tune it, what inputs and outputs it supports, how it was evaluated, and what limitations or risks users should understand. In Genesis, model cards help make models discoverable, reusable, comparable, and trustworthy across teams by documenting intended uses, performance, provenance, compute environment, licensing, and safety considerations. Model Card Template Integration How ModCon and AmSC Work Together: ModCon provides the scientific AI capability layer. AmSC provides the secure, federated platform that delivers it. Model teams access ModCon capabilities through a single onboarding path on AmSC, with identity, data, compute, and inference handled by the platform. ModCon capabilities move onto AmSC as supported services through a shared transition to operations process, so teams get research grade methods on production infrastructure. Contribute a Capability: ModCon is a partner ecosystem. Teams can contribute agents, models, workflows, and tools to the platform through a supported CI/CD and registration path. American Science Cloud Events Featured Event Genesis Mission: Hands-on Hackathon Accelerating the Path toward Success The Genesis Mission: Hands-on Hackathon is designed with one clear outcome in mind: every Genesis Mission RFA Award team leaves with a strong starting point for integrating their scientific workflow into the Genesis Mission Platform. The Hackathon will provide RFA Award teams with focused access to technical expertise, open capabilities and services, and computing resources to advance near-term project needs, resolve or characterize technical barriers, and identify common requirements that help inform continued development of ModCon and AmSC.
